首次上传到 GitHub

1. 在 https://github.com/new 新建仓库，例如 ai-life-classroom。
   使用免费 GitHub Pages 时可选择 Public，仓库内容和网站会公开。
   创建空仓库即可，不要再勾选 README、.gitignore 或许可证；本地已有首次提交。

2. 在 PowerShell 进入项目目录，运行下面的命令。
   把 YOUR_USERNAME 和仓库名换成你实际创建的地址。

   Set-Location 'E:\codex-workspace\ai-life-classroom'
   git remote add origin https://github.com/YOUR_USERNAME/ai-life-classroom.git
   git push -u origin main

   如果弹出 GitHub 登录窗口，按页面提示登录。不要把密码或令牌写进仓库文件。
   如果已经设置过 origin，用 git remote -v 检查，不要重复添加。
   如果远端已经有提交而推送被拒绝，先检查远端内容，不要使用强制推送。

3. 到 GitHub 仓库 Settings → Pages。
   Build and deployment 下的 Source 选择 GitHub Actions。
   注意：本仓库保留 dist 目录，使用随仓库提供的工作流发布；不是 main / (root) 的分支发布方式。

4. 进入 Actions，查看 Publish classroom to GitHub Pages。
   第一次推送发生在开启 Pages 之前时，可能发布失败。
   完成第 3 步后，打开该工作流，点 Run workflow，选择 main 再运行。
   成功后，Settings → Pages 中的 Visit site 就是可以分享的网址。

以后更新

   git add dist
   git commit -m "Update tutorial content"
   git push

main 分支的网站文件变化会触发自动发布；仅修改项目说明不会触发。
你也可以在 Actions 中手动运行发布任务。

发布范围
只发布 dist 中的网站文件。检查依赖、缓存、截图和 ZIP 不会被提交或发布。
初始化仓库并不等于已上传；本地没有自动创建 GitHub 仓库，也没有自动推送。
